## 왜 바꾸나

### 결과

| 8/5 → 9/23 | 수익률 |
|---|---|
| KOSPI | +7.31% |
| KODEX 200 (069500) 그냥 보유 | **+8.48%** |
| **이 계좌 (AI 매매)** | **−3.56%** |

격차 10.9%p를 대략 나누면:

| 원인 | 기여 |
|---|---|
| 주식 밖에 있던 돈 ⚠ (현금 평균 38.5% + 수동 매수 단기채 ETF 22% = 약 60%) | ≈ −3.2%p |
| 거래비용 (55건, 26.9만원) | ≈ −2.7%p |
| 종목·타이밍 | ≈ −5.4%p |

### AI 판단의 방향 (5일 수익률, 그날 판단 종목 평균 대비)

| 판단 | 초과수익 | t (자유도 12) | 의미 |
|---|---|---|---|
| BUY | −2.0% | −1.93 | 산 종목이 덜 올랐다 |
| SELL | +1.3% | +1.02 | 판 종목이 더 올랐다 |
| HOLD | +0.07% | +0.96 | 기준점 |

⚠ 이 표는 9/16까지 13일치다. 4일이 더 채점되자 BUY는 −0.8% 안팎으로 줄었고 SELL은 0과 구분되지
않는다("1일은 맞고 5일은 틀린다"도 재확인되지 않았다). 통계적으로 확정할 수준은 아니다(날짜 13개). 하지만 판단 채점·계좌 전체 격차·"판 뒤 반등 10건 중 8건"
세 측정이 같은 방향을 가리킨다. 9/7엔 SELL이 1일 기준으로 맞았는데 5일로는 틀렸다 —
**하루 움직임에 반응하고, 그게 며칠 뒤 되돌아온다.**

### 진단

AI가 보는 건 차트·컨센서스·공시·뉴스 제목, 전부 공개 정보다. 대상은 한국에서 가장 빨리
가격에 반영되는 시총 최상위 종목이다. 이 조합으로 시장을 이길 근거가 없는 상태에서
하루 3번 판단하며 회전하면, 비용과 현금 공백만 확정된다.

### 하지 않을 것

- **신호 뒤집기.** 유의하지 않은 신호를 뒤집으면 잡음에 비용만 얹는다.
- **최소 보유 강제.** 5일 기준 반사실은 −10만원 안팎 더 나빴다. ⚠ 다만 3일·10일은 부호가 반대라
  이 표본으로는 이롭다고도 해롭다고도 못 한다 — 근거 없이 넣지 않는다는 뜻이다.
- **자동매매 중단.** 사용자 결정 — 모의투자라 계속 돌리며 관찰한다.

## 구조

```
총자산
├─ 코어 70%   KODEX 200 (069500)   기계적으로 유지. AI는 손대지 않는다.
├─ 위성 ≤30%  개별 종목              AI 판단대로 매매 (지금 방식)
└─ 현금       나머지                 제비용 여유분
```

### 코어

- **AI 판단 대상에서 뺀다.** 069500은 프롬프트에 안 들어간다 — AI가 "시장"을 팔 수 없게.
- **규칙으로만 움직인다.** 코어 비중이 목표에서 **±5%p 넘게** 벗어나면 목표까지 맞춘다.
  밴드 안이면 가만히 둔다(회전 방지).
- 대부분 한 방향이다: 위성이 팔려 현금이 생기면 코어가 산다.
  ⚠ 단 밴드 안(65~75%)이면 사지 않는다. 지금처럼 코어가 66%일 때는 위성을 다 팔아도 코어 매수는 0주다
  (목표까지의 차이가 3주뿐이다). 밴드를 매수 쪽에서 떼려면 총자산을 장중가로 다시 계산해 넘기는 보정을
  같이 넣어야 한다 — plan_core는 장중 코어가를 직전 동기화 총자산과 비교해서, 밴드만 떼면 하락일마다
  사고 급등일에 되파는 왕복이 생긴다. 효과가 작아 미뤘다.

### 위성

- 지금 방식 그대로 AI가 BUY/SELL/HOLD.
- **위성 총액이 30%를 넘으면 BUY 금지.** SELL은 언제나 허용(손절 경로 유지).
- 종목당 비중 상한 25%, 1회 250만원, 하루 5건 — 기존 상한 유지.

### 비율을 70/30으로 잡은 이유

AI 판단의 기대값이 음수로 추정되는 상태다. 위성은 "AI 매매를 실제 체결로 계속 관찰하는 비용"이다.
30%면 AI가 지금처럼 틀려도 피해가 1/3로 줄고, 매매는 여전히 일어나 관찰이 이어진다.
AI가 이긴다는 증거가 쌓이면 위성을 넓힌다. 비율은 `AI_CORE_PCT` 변수 하나로 바꾼다.

## 이번엔 구조만 바꾼다 — 프롬프트는 그대로

AI를 "위험 감지" 쪽으로 돌리는 프롬프트 변경(예: 공시 악재 중심 매도)도 후보지만 **이번엔 안 한다.**
구조와 프롬프트를 같이 바꾸면 어느 쪽 효과인지 가를 수 없다(9/7 진입 위치 규율 때와 같은 원칙).
구조 효과를 먼저 재고, 프롬프트는 다음 단계다.

AI 판단 기록·채점은 지금과 똑같이 계속된다.

## 전환 — 두 가지 방법 (선택 필요)

현재: 현금 340만 / 개별 종목 620만(64%) — 4종목 모두 평가이익 중.
목표: 코어 약 675만 / 위성 약 290만.

| | A. 점진 (권장) | B. 즉시 |
|---|---|---|
| 방법 | 현금 340만으로 코어부터 산다. 위성은 강제로 안 판다 — AI SELL로 줄어드는 만큼 코어가 흡수 | 위성 초과분 약 330만을 지금 팔고 코어를 채운다 |
| 비용 | 강제 매도 비용 없음 ⚠ (코어 매수 수수료 0.35%는 든다 — 실제 21,580원) | 약 1.8만원(매도 제비용) |
| 단점 | 위성이 한동안 목표보다 크다(AI가 안 팔면 오래 간다) | 이익 중인 종목을 규칙 때문에 판다 |
| 측정 | 전환 기간이 섞인다 | 첫날부터 구조가 깨끗하다 |

A를 권한다. 비용이 없고, 위성 BUY는 초과 상태에서 바로 막히므로 위성이 더 커지지는 않는다.

## 구현 범위

| 파일 | 변경 |
|---|---|
| `decide.py` | 069500을 판단 대상에서 제외 / 코어 리밸런스 주문 생성 / 위성 초과 시 BUY 차단 |
| `daily.py` | 069500 일봉·분봉 수집 (ETF 제외 규칙의 **단일 예외** — 1종목이라 수집 시간 영향 없음) |
| `kiwoom_order.py` | 없음 — 069500 기준가가 `daily_prices`에 생기면 기존 경로로 흐른다 |
| 화면 | 대시보드에 코어/위성 비중과 각 수익률 표시 |
| 테스트 | 코어 밴드·위성 상한·AI 판단 제외·킬스위치 적용 |

### 그대로 유지되는 안전장치

- `AI_AUTOTRADE` 킬스위치 — 코어 주문도 같은 주문 경로라 함께 멈춘다
- 멱등 `(종목, 날짜, 방향)` — 코어도 하루 한 방향 1회
- 하루 5건 상한 — 코어 주문도 1건으로 센다
- 장중·휴장일·마감 후 게이트
- 키움 미러링 상한(1건 1,000만원 / 1,000주) — 코어 675만원 ≈ 60주로 안쪽

코어 주문은 decide 쪽 1회 250만원 상한에서 **제외**한다. 이 상한은 LLM이 수량을 잘못 키우는 걸
막으려는 것인데, 코어 수량은 LLM이 아니라 규칙이 정한다. 대신 "목표까지의 차이"를 넘지 못하고,
키움 미러링의 1,000만원 상한이 최종 방어선으로 남는다.
