# 체결 엔진 (3단계)

`lib/engine/` — 순수 함수. 라이브 모드와 리플레이 모드가 동일 엔진을 공유한다.

## 룩어헤드 차단 설계

```
fillOrder(order, nextBar, prevDayClose, config) → FILLED | REJECTED | PENDING
```

- 주문 1건을 **주문 접수 직후의 분봉 1개**에 대해서만 판정한다.
  미래 분봉은 시그니처상 입력받을 수 없다.
- 지정가 PENDING이면 호출측(리플레이 틱 / 라이브 폴링)이 다음 분봉이 생길
  때마다 다시 호출한다. 서버 커서 컷(4단계)과 이중 방어.

## 체결 규칙

| 규칙 | 구현 |
|---|---|
| 시장가 | 다음 분봉 **시가** + 슬리피지 5bp(config), 호가단위 절사(매수 올림·매도 내림), 가격제한폭 클램프 |
| 지정가 | 다음 분봉부터 고가·저가 범위에 지정가 터치 시 체결. 시가가 더 유리하면 시가 체결(갭 반영) |
| 상한가 | 시가가 상한가(전일 종가 ×1.3, 호가단위 내림) 이상이면 **매수 거부** |
| 하한가 | 시가가 하한가(×0.7, 호가단위 올림) 이하이면 **매도 거부** |
| 거래량 0 | 체결 불가(거부) — 거래정지 분봉 |
| 호가단위 | 2023-01 개편 표: ~2천 1원 / ~5천 5원 / ~2만 10원 / ~5만 50원 / ~20만 100원 / ~50만 500원 / 50만~ 1,000원. 지정가 검증 + 가격제한폭 검증 |
| 비용 | 수수료 0.015%, 매도 시 거래세 0.15%(2026-08 기준, config) — 원 단위 절사, 부동소수 경계 보정(EPS) |

설정은 `DEFAULT_CONFIG`(slippageBp 5, commissionRate 0.00015, sellTaxRate
0.0015). API 레벨에서 env(SLIPPAGE_BP 등)로 오버라이드 예정(4단계).

`estimateCost(side, price, qty)` — 주문 패널의 예상 비용 표시용(수수료·세금·총액).
